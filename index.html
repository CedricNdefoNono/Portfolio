GitHub deployment guide

Step 1 — Create your GitHub account and profile repository

Go to github.com and create a free account. Use a professional username — ideally cedric-nono-ndefo or nncd-consulting. Then create a special repository with your exact username — GitHub will use it as your public profile README.

Step 2 — Create the portfolio site repository

Create a new repository named portfolio. Upload the nncd_hub.html file you downloaded, rename it to index.html. In repository Settings → Pages, set Source to "Deploy from a branch", select main branch and /root. Your site will be live at your-username.github.io/portfolio within 2 minutes.

Step 3 — Create your 5 project repositories

Create one repository per portfolio project as you build each one. Each repository needs a README.md file that tells the story of the project — what it does, what problem it solves, how to run it, and which industries it applies to.

Step 4 — Connect GitHub profile to LinkedIn and your CV

Add your GitHub profile URL to your LinkedIn "Contact info" section and to the header of your CV. As you complete each project and push code to the repository, interviewers and potential NNCD clients can see your work in real time. Every commit is visible proof of active progress.

Updating the hub going forward

When you want to update the hub — add a completed project, adjust NNCD service pricing, or change any content — open the index.html file in GitHub directly, click the pencil edit icon, make your change, and click "Commit changes". The live site updates within 60 seconds. No coding tools required.
